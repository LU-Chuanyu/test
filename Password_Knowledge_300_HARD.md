# Password Knowledge — 300 道压题题库（C1–C2 真考难度版）

> ⚠️ **难度说明**：之前的版本对标 demo（B1/B2），这一版按**真考难度**重出，全部 **C1–C2**。
> 真考的常见陷阱是：
> 1. 干扰项里有 2 个看起来都对（考你能不能挑出**最准确**的那个）
> 2. 大量考"动词/形容词 + 介词"的**固定搭配**
> 3. 大量考**近义词辨析**（imply/infer、comprise/constitute、defuse/diffuse…）
> 4. 大量考**倒装、虚拟、混合条件**等高级语法
> 5. 大量考**学术 register**（hedging、formal vs informal）
>
> 题目格式：单句 + ABCD 单选，**只有一个最准确的答案**。
> 答案在文末，附**易错题解析**。

# 🔍 高频易错题解析（重点看这 30 题）

**Q4** `I'd rather you hadn't said that` — `would rather + 主语 + 过去时（现在/将来）/过去完成时（过去）`。这里指**过去**说过的话，所以用 `hadn't said`。

**Q5 / Q17 / Q36 / Q42 / Q45** 虚拟语气：`essential / insist / recommend / order / stipulate that + 主语 + 动词原形`（不加 -s，不用 should 也对）。

**Q6 / Q21 / Q24 / Q30** 倒装：否定副词 (`Hardly`, `No sooner`, `Not until`, `Rarely`, `Never`, `Seldom`, `Little`, `Only after`) 在句首 → 主谓倒装。

**Q14** "Long gone are the days when..." — 形容词 `gone` 提前 → `gone are` 倒装。

**Q23 / Q26 / Q31 / Q60** 虚拟省略 `if`：`Were he allowed` / `Had I known` / `Had there been` / `Had it not been for`。

**Q56** `Were + 主语 + to do` 是 `If + 主语 + were to do` 的倒装写法，表纯假设。

**Q60** 注意位置：`Had it not been for` ✓ ；`Hadn't it been for` ✗（缩写不能用于倒装）。

**Q66 vs Q71** `could have told me` (责备 = 你本来能说但没说) ；`might have informed us` (轻微责备/抱怨)。两者都对，挑题目里给的选项即可。

**Q68 vs Q78** `needn't have done` = 做了但没必要；`didn't need to do` = 不必做（通常没做）。Q68 已经订了机票（做了）→ `needn't have`；Q78 截止日是今天，他昨天交了 → 也是"做了但没必要" → `needn't have submitted`。

**Q72** `He can't have been driving` — "他不可能在开车"（执照吊销）。`mustn't` 不能表"不可能"。

**Q97 / Q99 / Q101 / Q105** Cleft 句：`What/All + S + V + is/are + N`，主语是名词性从句，谓语永远单数。

**Q108** Comma + 关系代词在介词后用 `whom`（人）/ `which`（物），所以 `half of whom`。

**Q113** `None of + 复数名词 + has/have` 都可，但正式书面语优先用 `has`（作单数）。

**Q117 abide BY** the rules（遵守）≠ abide with（容忍）。
**Q118 tantamount TO** = 等同于。
**Q119 devoid OF** = 缺乏。
**Q120 conducive TO** = 有助于。
**Q122 averse TO** = 反对、不喜欢（≠ adverse 不利的）。
**Q128 guard AGAINST** = 防止。
**Q133 implicated IN** a scandal = 牵涉其中。

**Q186 vs Q187** **imply** = 说话人暗示；**infer** = 听话人推断。
**Q188 comprise** = 由…组成（主动），`The committee comprises 12 members` ≠ `is comprised of` (后者也接受但被纯语法学家批评)。
**Q190 flout** rules = 公然违反；**flaunt** wealth = 炫耀。两者都拼 fl-，是真考最爱的陷阱。
**Q191 discreet** = 谨慎的；**discrete** = 离散的、独立的。
**Q192 defuse** tension = 缓和；**diffuse** = 扩散。
**Q198 proscribe** = 禁止；**prescribe** = 规定/开药。一字之差，意思相反。
**Q199 / Q200 assure 人 / ensure 事**（确保发生）/ insure 财物（投保）。
**Q201 pore over** = 钻研（细看）；**pour** = 倒水。

**Q268 / Q272 / Q298** `Notwithstanding` 后直接接名词或从句，意思 ≈ despite/although，但更正式。

**Q297** `albeit + 形容词/分词/介词短语`（不接完整句子），= although。

**Q299 insofar as** = "就…而言"，academic register 必备。
